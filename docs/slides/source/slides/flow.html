GUARDRAILS

Demographics stay in a separate table until after matching

Granite sees no dollar amounts and no demographics

Every generated note is validated, with a template fallback

Advisory only: any other decision is rejected

Demographic endpoints are token-gated

THE SYSTEM NEVER APPROVES, DENIES OR OVERTURNS A LOAN

11 / 18

Design flow. Match finds comparable approved applications using finances only. Evidence packages the differences, stated reasons and missing information. Explain checks the stated reasons against the reported data and produces a validated Granite note from facts only. Ask lets the reviewer query the evidence. Decide records one of three advisory outcomes with the model version. Guardrails run through every step, and the system never approves, denies or overturns a loan.
