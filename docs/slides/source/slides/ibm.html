Everything runs on IBM LinuxONE: this is an s390x instance with three vCPUs, the API runs as a systemd service next to the IBM-provided container where Granite 4 runs on llama dot cpp, and XGBoost trained inside that container. A live, simulated incoming application is matched against about nineteen hundred approved applications in roughly four milliseconds; throughput rises from 235 to about 460 requests a second with concurrent clients. Results are identical to a laptop, so the audit is reproducible. To be straight: it is not faster than a laptop here, and the zDNN backend gave no speed-up, so we claim none. The point is one controlled platform for a sensitive workflow.
