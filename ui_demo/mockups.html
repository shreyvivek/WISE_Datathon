HOW IT RUNS

Proposed build

FRONT ENDA single-page app in ui_demo/: plain HTML + JS + SVG, with the chart lib saved locally. No CDN, so it works offline.
BACK ENDThe existing FastAPI app serves it at /ui. One command: uvicorn src.api.main:app → open localhost:8000/ui. It can also point at the LinuxONE tunnel.
MODESStory: arrow keys step through the 7 screens for the video. Explore: free navigation and a case picker for judges' Q&A.
